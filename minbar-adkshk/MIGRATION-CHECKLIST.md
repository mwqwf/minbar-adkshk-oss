# قائمة اختبار الترقية الآمنة

## 1. فحوص آلية

- [x] `testDebugUnitTest` نجح (6 اختبارات)، ومنها `LocalStoreMigrationTest`.
- [x] `lintDebug` نجح دون أخطاء.
- [x] `assembleDebug` نجح.
- [ ] `bundleRelease` ينجح بمفتاح الرفع الحقيقي نفسه.
- [ ] راجع `applicationId=com.ali.menbaradkshk` و`versionCode=4` في AAB.

## 2. تثبيت جديد

- [ ] يفتح التطبيق بالعربية وRTL ولا يتعطل دون إنترنت.
- [ ] تظهر الأقسام والدروس عند الاتصال.
- [ ] تشغيل/إيقاف/تقديم/ترجيع/سرعة/طابور الصوت تعمل.
- [ ] يستمر الصوت في الخلفية وتعمل شاشة القفل وسماعة Bluetooth.
- [ ] التنزيل والتشغيل دون اتصال والحذف تعمل.
- [ ] الروابط `/lesson/<id>?t=<seconds>` و`/my-submissions` تفتح الوجهة الصحيحة.
- [ ] أذونات Android 13+ لا تمنع فتح التطبيق عند رفض الإشعارات.

## 3. اختبار ترقية Flutter → Kotlin

نفّذ هذا الاختبار عبر Google Play Internal Testing أو Closed Testing؛ لا تستخدم
APK Debug فوق نسخة Play لأن التوقيع مختلف.

- [ ] ثبّت الإصدار Flutter المنشور من Play.
- [ ] أنشئ مفضلة وسجلًا وقائمة تشغيل وموضع استكمال ولحظة محفوظة.
- [ ] نزّل درسًا وشغّله دون إنترنت.
- [ ] حدّد هدفًا أسبوعيًا ووقت الوِرد وقسمًا متابعًا.
- [ ] حدّث إلى AAB Kotlin من Play دون إزالة التطبيق.
- [ ] تحقق أن كل البيانات السابقة موجودة.
- [ ] تحقق أن ملف الصوت القديم يعمل دون إعادة تنزيل.
- [ ] أغلق التطبيق وافتحه مرتين؛ يجب ألا تتكرر الهجرة أو الإشعارات القديمة.
- [ ] افصل الشبكة وافتح التطبيق؛ يجب أن تظهر البيانات المخزنة.

## 4. Firebase والخادم

- [ ] Firestore يعرض `categories` و`subcategories` و`lessons`.
- [ ] `incrementLessonView` لا يوقف الصوت عند فشل الشبكة.
- [ ] `sendFeedback` يعمل بعد Anonymous Auth.
- [ ] رفع مساهمة أقل من 100MB ينشئ `lesson_submissions` بالمسار نفسه.
- [ ] حذف مساهمة معلقة ودالة `deleteMyData` تعملان.
- [ ] إشعارات FCM العامة وموضوع `sec_<id>` ونتائج المساهمات تصل.
- [ ] App Check Play Integrity ينجح في بناء Play الموقّع.

## 5. طرح تدريجي ورجوع

- [ ] ارفع AAB أولًا إلى Internal Testing.
- [ ] اختبر حسابًا/جهازًا جديدًا وجهازًا تمت ترقيته.
- [ ] انقل إلى Closed Testing الحالي بعد نجاح الفحوص.
- [ ] راقب الأعطال وANR وفشل التشغيل والتنزيل والمساهمات 48 ساعة.
- [ ] لا تحذف مشروع Flutter أو آخر AAB مستقر.
- [ ] عند عطل حرج، أوقف الطرح؛ لا تخفّض `versionCode`.
