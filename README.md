# منبر ادكصهك 🎙️

**تطبيق دروس صوتية إسلامية + لوحة إدارة متكاملة — مفتوح المصدر، منشور على Google Play.**

## الفكرة والغرض

منصة نشر دروس صوتية: يستمع المستخدم للدروس المصنّفة بأقسام عبر تطبيق جوال بنمط يوتيوب (تشغيل، تنزيل، قوائم، سجل، مفضّلة)، بينما يرفع المشرفون الدروس ويديرون المحتوى والمجتمع من تطبيق لوحة إدارة مستقل. التطبيق يعمل فعلياً ومنشور على المتجر.

## مكوّنات المستودع

| المجلد | المكوّن | التقنية |
|---|---|---|
| `minbar-adkshk/` | تطبيق المستخدم (`com.ali.menbaradkshk`) | Kotlin / Jetpack Compose |
| `minbar-adkshk-admin/` | لوحة الإدارة (`com.ali.ishaqiyin_admin`) | Kotlin / Jetpack Compose |
| `menbar_site/` | موقع التطبيق (سياسة الخصوصية + روابط عميقة assetlinks) | ويب ثابت |
| `minbar-admin-store/` | موقع لوحة الإدارة (سياسة الخصوصية) | ويب ثابت |

## أبرز الميزات

**تطبيق المستخدم:** تصفح أقسام ودروس صوتية، مشغّل متكامل مع مصغّر وسرعة/قفز/مؤقت نوم، تنزيل مع إيقاف/استئناف من نفس البايت، مفضّلة وقوائم تشغيل وسجل، بحث عربي مطبّع، وِرد يومي وسلاسل، لحظات ومشاركة بتوقيت، وضع قيادة، رائج ومميّز، متابعة أقسام، إشعارات وروابط عميقة، سمة ثلاثية (فاتح/داكن/نظام).

**لوحة الإدارة:** رفع دروس (حتى دمج 10 ملفات MP3 بدرس واحد)، إدارة أقسام بحذف تعاقبي، دردشة إدارة بنمط واتساب (وسائط، ردود خاصة، تفاعلات)، إشعارات مشرفين، تحليلات وجدولة وتمييز محتوى، نظام مساهمات «شارك درساً» بموافقة المشرفين، نص مشروح مع OCR.

## 🔐 المفاتيح والأسرار

هذا المستودع **لا يحتوي أي مفاتيح**: إعدادات Firebase مستبدلة بقيم `YOUR_*` (انظر `MinbarApplication.kt`). التطبيق المنشور يعمل بمفاتيحه الخاصة المحفوظة خارج هذا المستودع، وقاعدة بياناته محمية بقواعد أمان Firestore/Storage وApp Check.

## التشغيل

1. أنشئ مشروع Firebase (Firestore + Storage + Auth + FCM + Functions).
2. ضع قيم مشروعك مكان `YOUR_*` في `MinbarApplication.kt` (والمقابل في لوحة الإدارة).
3. افتح كل تطبيق في Android Studio وابنِ مباشرة (JDK 17+).
4. الموقعان ملفات ثابتة تُنشر على أي استضافة.
